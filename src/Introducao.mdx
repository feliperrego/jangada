# Jangada

Design system em React para produtos financeiros: tokens com tema claro e escuro, componentes acessíveis e testes que medem a acessibilidade em vez de supor.

- **Tokens como fonte única.** Cores, tipografia, espaços e raios saem de `tokens/tokens.json` e viram variáveis CSS e constantes TypeScript.
- **Acessibilidade medida.** Toda story passa pelo axe nos testes, e todo par de cor texto/fundo passa por um teste de contraste WCAG AA nos dois temas.
- **Comportamento do Radix, estilo e API próprios.** Diálogo, abas, seleção, checkbox e switch usam os primitivos do Radix para foco, teclado e ARIA; o visual e a forma de usar são da Jangada.

Use o botão **Tema** na barra de ferramentas para ver tudo no escuro.
